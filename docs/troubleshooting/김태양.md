# 김태양 — 트러블슈팅 & 회고

담당: 주문서/결제 페이지, 장바구니 페이지

## 트러블슈팅

- 장바구니, 주문, 결제 페이지는 기본적으로 상품, 로그인이 되어 있는 상태에서 작업이 가능했기 때문에 가상의 목업데이터로 작업을 진행해야 했다.
- 기능 구현은 어렵지 않았으나 기존의 다른 쇼핑몰과 비슷하게 만들기 위해서 CSS 작업에 많은 시간이 소요됨.
- 튜터님께서 도와주신 코드에서 Supabase로 DB를 연동하는 과정에서 해결 능력이 부족하여 손을 댈 수 없었음.
- AI에게 물어보고 작업을 진행하려 하였으나 기존 코드와 경로에서 오류가 발생함.
- 그 외 기타 자잘한 문제가 많았고 해결하는 데 어려움을 겪음.

## 회고

- 기존에 HTML은 어떻게 진행해야 할지 어느 정도는 알 수 있고, 기능적인 측면보다는 CSS에서 더 많은 어려움을 겪었으나, React에서는 시작부터 손을 댈 수 없었음.
- 결국 모든 부분에서 AI의 도움을 받아야 했으며, 더 많은 공부가 필요함을 느낌.
- 바이브 코딩의 위력을 처음으로 체감함.
- 결국 사용을 하지 않을 수는 없겠으나, 현 단계에서는 사용하는 것을 지양해야겠다고 생각함.
- 복습하고 공부하는 데 더 많은 시간이 필요함을 느낌.
